# 🚀 مركز الإنتاجية

تطبيق متكامل لإدارة المهام والمحاسبة المالية باللغة العربية مع تصميم داكن أصيل.

## ✨ المميزات

- 📝 **إدارة المهام** - أضف وحذف المهام وتابع إنجازك
- 💰 **المحاسبة المالية** - إدارة الدخل والمصروفات
- 📊 **تقارير وإحصائيات** - شاهد ملخص أموالك ومهامك
- 🎨 **تصميم عصري داكن** - واجهة جميلة وسهلة الاستخدام
- 💾 **حفظ تلقائي** - بيانات آمنة في المتصفح

## 🎯 كيفية الاستخدام

1. افتح الموقع في المتصفح
2. اختر من القائمة العلوية:
   - **الرئيسية** - الصفحة الرئيسية
   - **إدارة المهام** - أضف مهامك
   - **المحاسبة المالية** - تابع أموالك

## 📱 الأجهزة المدعومة

- ✅ الحواسيب المكتبية
- ✅ الأجهزة اللوحية
- ✅ الهواتف الذكية

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage للحفظ

## 📄 الملفات الرئيسية

- `index.html` - الهيكل الأساسي للموقع
- `style.css` - التصميم والألوان
- `script.js` - الوظائف والبرمجة
